# 验证记录

自动化测试由 CI 在每次推送时运行（`npm test`：后端集成测试连真实 Postgres，前端组件测试用 jsdom）。本文件记录需要真实环境的手工验证。

## E · 答题主流程前端（2026-11-11）

**环境**：
- 本机执行 `npm run build`，然后用 `PORT=3100 npm start` 以生产模式启动，前端和接口由同一个服务提供。
- 数据库是本地开发库（Docker Compose 的 Postgres 17）。
- 浏览器是 Chromium 内核，由 AI 用浏览器自动化工具操作。
- 浏览器窗口处于最小化状态，无法截图，下面的证据用页面状态和数据库查询代替。
