### 测试覆盖的核心场景

题面要求"至少覆盖一个正常流程和两个重要异常或边界场景"。`server/test/api-flow.test.ts` 用真实接口和数据库，覆盖大纲 §6 的 9 个端到端场景：

| # | 场景 | 类型 |
|---|---|---|
| 1 | 开始 → 逐题作答 → 完成 → 总结数字与预期一致 | 正常流程 |
| 2 | 重复提交同一个幂等键只记一次，统计不变 | 重复操作 |
| 3 | 先答错再订正：归为订正后做对，首次正确率不受影响 | 统计口径 |
| 4 | 非法输入不计尝试次数 | 输入校验 |
| 5 | 未作答时请求解析被拒绝；答错或跳过后可以获取 | 访问规则 |
| 6 | 已答对的题再次提交不改变记录 | 重复操作 |
| 7 | 并发提交时尝试序号不重复 | 并发 |
| 8 | 跳过后进入下一关；会话结束后提交返回 409；总题数包含没作答的题 | 边界 |
| 9 | 先打开解析再答对：归为订正后做对 | 统计口径 |

## 5. 已知问题与限制

| 限制 | 影响 | 应对 |
|---|---|---|
| 没有登录，只有匿名标识 | 换浏览器或清除缓存后，找不到原来的记录（数据仍在库里） | 题面不要求登录 |
| 会话 ID 就是访问凭证 | 拿到会话 ID 的人可以代为作答 | 会话 ID 是随机 UUID，无法猜测 |
| Render 免费实例闲置后会休眠 | 第一次打开约需 30–60 秒 | 展示前先打开一次 |
| 免费 Postgres 约 30 天后过期，没有自动备份 | 过期后作答记录丢失；题库由启动流程自动重建 | 需要时用 `pg_dump` 手动导出（[deploy.md](deploy.md)） |
| 限流计数在内存中 | 重启后清零；只有一个实例 | 免费档只有一个实例 |
| 视频字幕原先叠在画面上，遮挡底部的图形与标注（用户测试发现） | 已在 K 中修复：字幕显示在视频下方，视频底部留出安全区 | — |
| 视频是公开的静态文件 | 知道地址的人可以在答题前看到讲解和答案 | 页面只在可以看解析时显示入口 |
| 正文用系统黑体 | 各平台的正文外观略有差异 | 标题使用自托管的思源宋体 |
| 免费档构建偶尔很慢 | 部署 I 时，构建约 16 分钟触发了平台超时，重新部署后成功 | [deploy.md](deploy.md) 的"常见故障" |

## 8. 复用内容与素材来源

- **开源依赖**（见各 `package.json`）：Fastify、Drizzle ORM、pg、zod、@fastify/static、@fastify/rate-limit、React、Vite、Vitest、Testing Library、ESLint、Prettier。
- **字体**：
  - 网页标题：Noto Serif SC，经 [Fontsource](https://fontsource.org/) 自托管，SIL OFL 1.1；
  - 视频画面：Noto Sans/Serif CJK SC，SIL OFL 1.1，只在生成时使用，不随仓库分发。
- **题目、解析、常见错误**：12 题的题型、数据和答案列在项目大纲 §2.3 中（AI 起草，本人确认大纲 v0.2）；题干、分步解析和常见错误提示由 AI 编写。`question-bank.test.ts` 逐题核对答案和单位与大纲一致，并检查每题至少 3 步解析、至少 1 个常见错误。
- **视频**：分镜与绘制脚本由 AI 编写，旁白用 edge-tts 合成。详见 [video-assets.md](video-assets.md)。
- **视觉设计**：先在 Claude Design 中出视觉稿（AI 绘制，本人确认），再实现为代码。
- **没有复用**任何现成的项目模板或第三方题库。
