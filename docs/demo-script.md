# 展示流程（约 8 分钟）

## 开场前

- [ ] 提前 5 分钟打开 <https://polygon-area-practice.onrender.com>，唤醒免费实例（休眠时第一次打开要 30–60 秒）。
- [ ] 运行 `npm run smoke -- https://polygon-area-practice.onrender.com`，6 步全部通过。
- [ ] 用一个**全新的浏览器窗口**（无痕模式即可）演示，确保首次引导会出现、进度从零开始。
- [ ] 备用：线上不可用时，在本机运行 `docker compose up --build`，打开 <http://localhost:3000>。
- [ ] 另开标签页准备好：GitHub 上的 PR 列表、CI 运行记录、Render 控制台的 Logs。

## 学生体验（约 5 分钟）

| # | 操作 | 要讲的点 |
|---|---|---|
| 1 | 打开首页，跟着引导走 4 步 | 情境任务"图形小镇"；4 关对应 4 种图形，每做对一题建筑盖高一层，三题都做对就点亮 |
| 2 | 第 1 题填 `40`（正确） | 后端判题；圆圆"一次就做对了"；面包店长出第 1 层 |
| 3 | 第 2 题填 `26`，第 3 题填 `4` | 第 3 题后屋顶落下、窗户依次亮灯：建筑状态只来自后端，动画只在当下的变化时播放 |
| 4 | 第 4 题填 `60`（常见错误） | 针对 60 的提示"别忘了 ÷ 2"；图形上补出另一个三角形，拼成平行四边形；圆圆歪头思考 |
| 5 | 点"看视频讲解"，播放几秒，拖到最后 | 学生自选图文或视频；有字幕；开始播放和播放到结尾分别记录学习事件 |
| 6 | 第 4 题填 `30` | "改正成功"；这题会计入"订正后做对" |
| 7 | 第 5 题直接"先跳过"，第 6 题填 `54` | 跳过不算作答；本关的题都做过就能去下一关 |
| 8 | 刷新页面 | 进度从后端恢复：第 6 题显示"这一题完成了"，建筑直接显示当前阶段，不重播动画。点"去当前题"进入第 7 题 |
| 9 | 第 7 题填一个非法答案，比如 `40cm²` | 后端返回原因"只填数字就好，单位已经写好了。"，不计作答次数 |
| 10 | "提前结束" → 确认 | 进入总结页："这次点亮了 1 座建筑"，首次正确率 33%（4/12）、最终完成率 42%（5/12）；建议里有"第 4 题看完了视频解析后做对了""第 5 题跳过了"；可以回看题目和解析 |
| 11 | 点"练习记录" | 旧练习的总结保留可查 |

## 工程侧（约 3 分钟）

| 要讲的点 | 展示什么 |
|---|---|
| 统计口径 | README"统计口径"：一次做对要求第 1 次正确且之前没看过解析；先后关系按 `seq` 判断；非法输入不计次 |
| 可靠性 | 幂等键 + 唯一约束 + 行锁；结果不确定时用同一个键重试；`api-flow.test.ts` 的 9 个场景 |
| 测试与 CI | 后端 306 个（真实 PostgreSQL）、前端 187 个；GitHub Actions 的运行记录 |
| 部署与排障 | Render Blueprint；用冒烟检查验收；日志按 `reqId` 定位；代理层数的实测（1 → 2 → 3） |
| AI 协同 | [ai-collaboration.md](ai-collaboration.md) 的 3 段记录；AI 出错是怎么被测试、实跑和评审发现的 |

## 可能被问到的问题

| 问题 | 回答要点 |
|---|---|
| 为什么用 PostgreSQL 而不是 SQLite？ | Render 免费档的磁盘是临时的；需要部分唯一索引、行锁和序列来保证并发一致 |
| 重复提交怎么处理？ | 前端为每次操作生成幂等键；后端用唯一约束兜底，重放时从记录重新算出首次结果 |
| 先错后对，再重放第一次请求，返回什么？ | 返回第一次的结果（答错），`session` 是当前状态；前端在两者矛盾时不显示答错 |
| 页面显示成功但后端没保存，会发生吗？ | 不会：只有后端确认后才显示；结果不确定时明确提示，并锁定输入等待重试 |
| 视频是怎么做的？ | Python 逐帧绘制，数字从题库算出并断言等于答案；edge-tts 旁白；一条命令可以重新生成 |
| 哪些是你自己判断的？ | 见 ai-collaboration.md 的"分工"：选题与技术栈、每份方案的评审、范围调整、视觉方向、字体与 TTS 的选择 |
