# Proposal

## Why

现在线上版本的"建造小镇"只有文字（"施工中 2/3""面包店点亮了！"），对五年级学生吸引力不够。题面把"学生体验"列为评分项，大纲 §3 也把"图形小镇建造师"作为核心互动。视觉稿已经用户确认（Claude Design 画布"图形小镇视觉稿"），方向是精致的插画感，不要低幼感。本次把它落地。

## What Changes

- **建筑**：
  - 四座建筑用 SVG 组件绘制：面包店（平行四边形）、帐篷营地（三角形）、小桥（梯形）、小镇广场（组合图形）。
  - 建筑的阶段由后端进度决定：本关已做对几题，就盖到第几层；3 题都做对时点亮。
- **动画**：
  - 答对一题，新的一层落下；点亮时窗户依次亮灯，暖光扩散。
  - 动画只在本次操作让状态变化时播放；刷新页面或进入页面时直接显示当前阶段，不重播。
  - 系统开启"减少动态效果"时不播放动画。
- **圆圆**：
  - SVG 角色，五种状态：待机、一次做对、订正后做对、答错思考、过关庆祝。
  - 答题反馈改为圆圆的反应加一句话。措辞只描述发生过的事，不说"看懂了"（顺带修正 E 遗留的"看懂了再做对"）。
- **答错时的图形提示**：按图形在题目图上画辅助线。例如三角形补出另一半拼成平行四边形，L 形补齐缺掉的一块。
- **首页**：
  - 改为小镇地图：四座建筑分为已点亮、施工中、未解锁三种状态；
  - 旁边是圆圆的欢迎语和进度卡片。
- **首次进入引导**：圆圆分 4 步介绍玩法，高亮对应区域；可以跳过，只出现一次。
- **视觉语言**：首页、答题页、总结页、练习记录页统一使用视觉稿的色板、字体层级和控件样式。答题页增加当前关卡的建筑面板，总结页顶部是小镇全景。

## Capabilities

### New Capabilities
- `town-display`：小镇与建筑如何反映后端进度：各页面显示哪些建筑、阶段与点亮的规则、动画什么时候播放、什么时候不播放。
- `companion-feedback`：圆圆在各种反馈中的状态与措辞规则。
- `figure-hints`：答错后题目图形上的辅助提示。
- `onboarding-guide`：首次进入时的引导：内容、出现条件、跳过与键盘操作。

### Modified Capabilities

（无。practice-pages 的"判题反馈"只规定反馈的类型，没有规定措辞和形式，本次不改变它的要求。）

## Impact

- 新增：
  - `web/src/town/`：建筑组件、小镇地图、点亮效果；
  - `web/src/companion/`：圆圆组件、反馈措辞；
  - `web/src/practice/FigureHint`：图形辅助线；
  - `web/src/onboarding/`：首次引导；
  - 以上各部分的组件测试。
- 修改：
  - `HomePage`、`PracticePage`（反馈和建筑面板）、`SummaryPage`（顶部全景）、`HistoryPage`（样式）；
  - `index.css`：重写为视觉稿的设计 token。
- 后端不改：阶段与点亮所需的数据（`solvedCount`、`lit`、`stageLit`、`outcome`、`mistakeHint`）已经由 D 提供。
- 不加新依赖：动画用 CSS 实现（见 design D3）。
- 不在范围内：音效、3D、视频解析（I）。
