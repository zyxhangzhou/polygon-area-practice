# Spec Delta

## Purpose

规定答错后题目图形上的辅助提示：用一条辅助线或补出的一块图形，把"公式从哪里来"画出来，帮助学生自己发现错在哪里，而不是直接给出答案。

## ADDED Requirements

### Requirement: 答错后显示辅助线
后端确认这次作答答错后，答题页的图形上 SHALL 按图形类型显示辅助提示：
- 三角形、直角三角形：补出一个同样的三角形，与原图拼成平行四边形，并标注"复制一个，拼成平行四边形"；
- 平行四边形：突出高（虚线和直角标记），并标注"高要和底垂直"；
- 梯形：补出一个倒过来的同样的梯形，拼成平行四边形，并标注"两个梯形拼成平行四边形"；
- 组合图形（小房子）：画出分割线，分成长方形和三角形；
- 组合图形（L 形）：用虚线补出缺掉的长方形，标注"先补成大长方形，再减去"。

辅助提示 MUST NOT 显示答案或算式的结果。辅助提示 MUST 有文字说明，读屏软件可以读到。做对、重新进入题目或刷新页面后，辅助提示不再显示。

#### Scenario: 三角形答错
- **WHEN** 第 4 题提交 `60`，后端判为答错
- **THEN** 图形上补出另一个三角形，与原图拼成平行四边形，并显示文字说明

#### Scenario: 做对后消失
- **WHEN** 辅助提示显示时，再答对
- **THEN** 不再显示辅助提示

#### Scenario: 不泄露答案
- **WHEN** 任何辅助提示
- **THEN** 图形和标注中不出现这道题的答案
