# Spec Delta

## ADDED Requirements

### Requirement: 启动时准备数据库
服务 SHALL 在开始监听端口之前，依次执行数据库迁移和题库种子。迁移或种子失败时（包括数据库不可达），服务 MUST 输出错误原因并以非零退出码退出，不得在表结构或题库缺失的状态下对外提供服务。迁移 MUST 可以重复执行：已执行过的迁移不再执行。

#### Scenario: 空数据库上启动
- **WHEN** 指向一个空数据库启动服务
- **THEN** 服务完成迁移与种子后开始监听
- **AND** `GET /api/health` 返回 200，库中有 12 道题

#### Scenario: 重复启动
- **WHEN** 对已经迁移过的数据库再次启动服务
- **THEN** 服务正常启动，不重复执行已执行的迁移，题目仍为 12 道

#### Scenario: 启动时数据库不可达
- **WHEN** `DATABASE_URL` 指向不可达的地址时启动服务
- **THEN** 进程以非零退出码退出
- **AND** 输出中说明数据库准备失败
