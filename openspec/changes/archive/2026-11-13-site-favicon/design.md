# Design

## Context

页面左上角的标志在 `web/src/ui/Brand.tsx` 中是内联 SVG（34×34 网格）：陶土色 `#C66B43` 的平行四边形是房身，蓝灰色 `#3F6175` 的三角形是屋顶。站点没有任何图标文件。生产环境由 Fastify 托管 `web/dist`；带扩展名的缺失文件返回 404（app-hosting 规格），所以现在 `/favicon.ico` 是 404。

## Goals / Non-Goals

**Goals:**
- 标签页、书签、iOS 主屏幕都显示与页面标志一致的图标；16px 时仍能认出图形。
- 浅色和深色的浏览器主题下都看得清。

**Non-Goals:**
- 不做 PWA（不加 manifest、离线缓存）。
- 不改页面内标志的样式。

## Decisions

### D1 图形与底色

图形直接取自页面标志，平移并放大到 32×32 网格中，占约 26×26：房身 `(3,29) (11,11) (29,11) (21,29)`，屋顶 `(11,11) (16,3) (21,11)`。底下是米色 `#F7F2E9`（页面背景色 `--paper`）圆角方块，圆角 7，描 1px `#E6DCCE` 边。

- 为什么加底色：透明底的蓝灰色屋顶在深色标签栏上几乎看不见；米色方块在两种主题下都有足够的对比。
- 为什么不另画新图形：标签页图标应该和页面标志一致，学生和家长才能对上。

### D2 文件与格式

| 文件 | 用途 |
|---|---|
| `favicon.svg` | Chrome、Edge、Firefox 等现代浏览器；`<link rel="icon" type="image/svg+xml">` |
| `favicon.ico`（16/32/48） | Safari 的标签页、旧浏览器，以及不读 HTML 直接请求 `/favicon.ico` 的场景；`<link rel="icon" href="/favicon.ico" sizes="any">` |
| `apple-touch-icon.png`（180） | iOS 添加到主屏幕；不透明、直角，系统会自己裁圆角 |

ICO 中的每个尺寸单独绘制（8 倍超采样后缩小），不是从大图缩小，小尺寸边缘更清晰。

**备选**：只放一个 SVG。没有采用，因为 Safari 的标签页不支持 SVG 图标，直接请求 `/favicon.ico` 仍是 404。

### D3 生成方式

`scripts/build_icons.py` 用 Pillow 生成 3 个文件，图形坐标和颜色只在脚本里写一次。生成结果提交到仓库，构建和部署不需要 Python。脚本可以用视频生成的虚拟环境运行（已经装了 Pillow）。

### D4 缓存

不加文件名哈希，沿用 `@fastify/static` 的默认缓存头。图标很少改；真要改时，浏览器会按协商缓存重新验证。

## Risks / Trade-offs

- 浏览器会长期缓存 favicon，用户可能要强制刷新才能看到新图标 → 只影响已经打开过网站的浏览器，验证时用新的浏览器配置或强制刷新。
- 16px 下屋顶只有约 5 像素宽 → 已在 16、32、48 三个尺寸下预览，形状可以认出。
